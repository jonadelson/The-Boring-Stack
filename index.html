The Boring Stack

The technologies nobody tweets about, quietly running everything.

This site teaches the unglamorous technologies that are very often the right choice: HTML, CSS, plain JavaScript, Postgres, HTTP, and the security practices that hold it all together. It practices what it preaches — every page here is hand-written HTML and CSS with no framework, no build step, and exactly one sprinkle of vanilla JavaScript, added the boring way in lesson 10.

Tap "view source" on any page. The site itself is the first example in every lesson.
