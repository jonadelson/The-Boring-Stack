The Boring Stack

The technologies nobody tweets about, quietly running everything.

This site teaches the unglamorous technologies that are very often the right choice: HTML, CSS, plain JavaScript, Postgres, HTTP, and the security practices that hold it all together. It practices what it preaches — every page here is hand-written HTML and CSS with no framework, no build step, and (so far) no JavaScript at all.

Tap "view source" on any page. The site itself is the first example in every lesson.

The roadmap

This site will grow in phases, and each phase's reason to exist is itself a lesson about when complexity earns its keep:

  1. Static pages — HTML and CSS fundamentals. (You are here.)
  2. Interactivity — quizzes with vanilla JavaScript and localStorage.
  3. A server and Postgres — added only when localStorage's limits start to hurt.
  4. Authentication — sessions, password hashing, CSRF: security learned by building it.
  5. Operations — deployment, TLS, logs, backups.
